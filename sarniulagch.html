Физикийн хичээл: Сарниулагч линз

9-р анги | Сарниулагч линзэнд дүрс байгуулах ба линзийн өсгөлт

Бэлтгэсэн: Цаст-Алтай сургуулийн физикийн багш М.Амгалан

Сарниулагч линз гэж юу вэ?

Дунд хэсгээрээ нимгэн, захаараа зузаан линзийг сарниулагч линз гэнэ. Сарниулагч линз дээр гол оптик тэнхлэгтэй параллелиар туссан гэрлийн цацрагууд линзээр хугарсны дараа тал тал тийш сарнин тарах бөгөөд тэдгээрийн хуурмаг үргэлжлэлүүд линзний өмнөх нэг цэгт огтлолцдог. Уг цэгийг линзийн хуурмаг фокус (F) гэнэ.

Линзийн гэрэл сарниулах зарчим:

Параллелиар туссан цацрагууд линзээр нэвтрэхдээ гадагш сарнидаг. Тэдгээрийн үргэлжлэлүүд линзний урд орших хуурмаг фокус (F) цэг дээр уулздаг тул сарниулагч линзийг сөрөг фокусын зайтай гэж үздэг.

Линзийн гол элементүүд:

  • Оптик төв (O): Линзийн төв цэг. Энэ цэгийг дайрсан цацраг хугарахгүй шууд нэвтэрнэ.
  • Хуурмаг Фокус цэг (F): Сарнин гарсан цацрагуудын үргэлжлэл уулзах цэг. Линз зүүн талдаа хуурмаг фокустай байна.
  • Давхар фокус (2F): Фокусын зайнаас яг 2 дахин хол зайд орших цэг.
  • Гол оптик тэнхлэг: Линзийн оптик төв болон фокусуудыг дайрсан шулуун.

Дүрс байгуулахад ашиглах гол 2 цацраг:

Сарниулагч линзэнд дүрс байгуулахад дараах хоёр хялбар цацрагийг ашигладаг:

  • Параллель цацраг: Гол оптик тэнхлэгтэй параллелиар туссан цацраг линзээр хугараад, түүний хуурмаг үргэлжлэл нь урд талын фокус (F)-ыг дайрна.
  • Оптик төвийг дайрах цацраг: Оптик төв (O) цэг рүү чиглэн туссан цацраг чиглэлээ өөрчлөхгүй шууд нэвтэрнэ.

Тэмдэглэгээ ба нэгж:

• a: Линзээс биет хүртэлх зай (м эсвэл см)

• F: Линзийн фокусын зай (м эсвэл см)

Үүссэн дүрсний төлөв байдал:

Сарниулагч линзийн бодлогууд

Дараах 10 бодлогыг бие даан бодоод "Бодолт харах" товчлуур дээр дарж шалгаарай.

Бодлого 1

Сарниулагч линзийн фокусын зай $F = 15\text{ см}$. Линзээс $a = 30\text{ см}$ зайд биетийг байрлуулсан бол дүрс линзээс ямар зайд ($b$) үүсэх вэ?

Бодолт:

Өгөгдсөн нь: $F = 15\text{ см}$, $a = 30\text{ см}$.

Сарниулагч линзийн томьёо: $-\frac{1}{F} = \frac{1}{a} - \frac{1}{b}$

Эндээс $\frac{1}{b}$-ийг олбол: $\frac{1}{b} = \frac{1}{a} + \frac{1}{F}$

Утгуудыг орлуулвал: $\frac{1}{b} = \frac{1}{30} + \frac{1}{15} = \frac{1 + 2}{30} = \frac{3}{30} = \frac{1}{10}$

Хариу: $b = 10\text{ см}$ (Линзийн урд $10\text{ см}$ зайд хуурмаг дүрс үүснэ).

Бодлого 2

Биет сарниулагч линзээс $a = 20\text{ см}$ зайд байхад түүний хуурмаг дүрс линзээс $b = 5\text{ см}$ зайд үүсжээ. Линзийн шугаман өсгөлт $k$-г ол.

Бодолт:

Өгөгдсөн нь: $a = 20\text{ см}$, $b = 5\text{ см}$.

Шугаман өсгөлтийн томьёо: $k = \frac{b}{a}$

Орлуулвал: $k = \frac{5\text{ см}}{20\text{ см}} = 0.25$

Хариу: $k = 0.25$ (Дүрс биетээс 4 дахин жижиг үүснэ).

Бодлого 3

Сарниулагч линзэнд үүссэн дүрсийн өндөр $h = 4\text{ см}$, линзийн өсгөлт $k = 0.2$ байв. Эх биетийн өндөр $H$-ийг олно уу.

Бодолт:

Өгөгдсөн нь: $h = 4\text{ см}$, $k = 0.2$.

Өсгөлтийн томьёо: $k = \frac{h}{H} \implies H = \frac{h}{k}$

Орлуулвал: $H = \frac{4\text{ см}}{0.2} = 20\text{ см}$

Хариу: $H = 20\text{ см}$.

Бодлого 4

Фокусын зай нь $F = 20\text{ см}$ байдаг сарниулагч линзийн оптикийн хүч $D$-г диоптриор (дптр) олно уу.

Бодолт:

Өгөгдсөн нь: $F = 20\text{ см} = 0.2\text{ м}$. Сарниулагч тул $F = -0.2\text{ м}$.

Оптикийн хүчний томьёо: $D = \frac{1}{F}$

Орлуулвал: $D = \frac{1}{-0.2\text{ м}} = -5\text{ дптр}$

Хариу: $D = -5\text{ дптр}$.

Бодлого 5

Линзээс $a = 60\text{ см}$ зайд орших биетийн хуурмаг дүрс линзээс $b = 15\text{ см}$ зайд үүссэн бол линзийн фокусын зай $F$-ийг ол.

Бодолт:

Өгөгдсөн нь: $a = 60\text{ см}$, $b = 15\text{ см}$.

Сарниулагч линзийн хувьд: $\frac{1}{F} = \frac{1}{b} - \frac{1}{a}$

Орлуулвал: $\frac{1}{F} = \frac{1}{15} - \frac{1}{60} = \frac{4 - 1}{60} = \frac{3}{60} = \frac{1}{20}$

Хариу: $F = 20\text{ см}$ (Сарниулагч тул $F = -20\text{ см}$).

Бодлого 6

$H = 10\text{ см}$ өндөртэй биет $F = 10\text{ см}$ фокусын зайтай сарниулагч линзээс $a = 40\text{ см}$ зайд байрлана. Дүрсийн өндөр $h$-ийг олно уу.

Бодолт:

1) Дүрс хүртэлх зай $b$-г олох: $\frac{1}{b} = \frac{1}{a} + \frac{1}{F} = \frac{1}{40} + \frac{1}{10} = \frac{5}{40} = \frac{1}{8} \implies b = 8\text{ см}$.

2) Өсгөлт $k = \frac{b}{a} = \frac{8}{40} = 0.2$.

3) Дүрсийн өндөр $h = k \cdot H = 0.2 \times 10\text{ см} = 2\text{ см}$.

Хариу: $h = 2\text{ см}$.

Бодлого 7

Оптикийн хүч нь $D = -4\text{ дптр}$ байх линзээс $a = 50\text{ см}$ зайд биетийг байрлуулав. Дүрс линзээс ямар зайд үүсэх вэ?

Бодолт:

1) Фокусын зай $F = \frac{1}{|D|} = \frac{1}{4} = 0.25\text{ м} = 25\text{ см}$.

2) $\frac{1}{b} = \frac{1}{a} + \frac{1}{F} = \frac{1}{50} + \frac{1}{25} = \frac{1 + 2}{50} = \frac{3}{50}$

3) $b = \frac{50}{3} \approx 16.67\text{ см}$.

Хариу: $b \approx 16.67\text{ см}$.

Бодлого 8

Сарниулагч линзийн фокусын зай $F = 20\text{ см}$. Дүрс линзээс $b = 12\text{ см}$ зайд үүссэн бол биет линзээс ямар зайд ($a$) байрласан бэ?

Бодолт:

Томьёо: $\frac{1}{b} = \frac{1}{a} + \frac{1}{F} \implies \frac{1}{a} = \frac{1}{b} - \frac{1}{F}$

Утгуудыг орлуулвал: $\frac{1}{a} = \frac{1}{12} - \frac{1}{20} = \frac{5 - 3}{60} = \frac{2}{60} = \frac{1}{30}$

Хариу: $a = 30\text{ см}$.

Бодлого 9

Биет линзээс $a = 50\text{ см}$ зайд байхад сарниулагч линзийн өсгөлт $k = 0.4$ байв. Уг линзийн фокусын зай $F$-ийг ол.

Бодолт:

1) Дүрс хүртэлх зай $b = k \cdot a = 0.4 \times 50\text{ см} = 20\text{ см}$.

2) Фокусын зайг олох: $\frac{1}{F} = \frac{1}{b} - \frac{1}{a} = \frac{1}{20} - \frac{1}{50} = \frac{5 - 2}{100} = \frac{3}{100}$

3) $F = \frac{100}{3} \approx 33.33\text{ см}$.

Хариу: $F \approx 33.33\text{ см}$.

Бодлого 10

$H = 15\text{ см}$ өндөртэй биетийг сарниулагч линзийн өмнө $a = 40\text{ см}$ зайд тавихад $h = 3\text{ см}$ өндөртэй дүрс үүсэв. Линзийн оптикийн хүч $D$-г ол.

Бодолт:

1) Өсгөлт $k = \frac{h}{H} = \frac{3}{15} = 0.2$.

2) Дүрс хүртэлх зай $b = k \cdot a = 0.2 \times 40\text{ см} = 8\text{ см}$.

3) $\frac{1}{F} = \frac{1}{b} - \frac{1}{a} = \frac{1}{8} - \frac{1}{40} = \frac{5 - 1}{40} = \frac{4}{40} = \frac{1}{10} \implies F = 10\text{ см} = 0.1\text{ м}$.

4) Оптикийн хүч $D = -\frac{1}{F} = -\frac{1}{0.1\text{ м}} = -10\text{ дптр}$.

Хариу: $D = -10\text{ дптр}$.
