📐 1. Штангенциркуль ашиглан хэмжих

Бүтэц ба Нарийвчлал

Штангенциркуль нь миллиметрээс бага буюу 0.1 мм эсвэл 0.05 мм-ийн нарийвчлалтай хэмжилт хийдэг багаж юм.

Хуваарийн үнэ ($C$) ба заалт бодох томьёо: $$C = \frac{1\text{ мм}}{\text{Нониусын хуваарийн тоо } (N)}$$ $$\text{Нийт урт } L = L_{\text{үндсэн}} + (n \times C)$$
  • $L_{\text{үндсэн}}$: Нониусын 0 зурааснаас өмнөх үндсэн хуваарийн бүхэл миллиметр
  • $n$: Үндсэн хуваарийн зураастай яв цав давхцсан нониусын зураасын дугаар

Штангенциркулийн заалт унших жишээ:

Жишээ бодолт: Нониусын 0 зураас 12 мм-ийн ард байна. 4 дэх зураас давхцсан ($C=0.1\text{ мм}$).
$$\text{Заалт } L = 12\text{ мм} + (4 \times 0.1\text{ мм}) = \mathbf{12.4\text{ мм}}$$

🔬 2. Микрометр ашиглан хэмжих

Микрометрийн бүтэц ба зарчим

Микрометр нь штангенциркулиас илүү өндөр буюу 0.01 мм (10 мкм) нарийвчлалтай хэмждэг багаж юм. Металл утасны диаметр, нимгэн цаасны зузааныг хэмжихэд тохиромжтой.

Микрометрийн заалт унших томьёо: $$L = L_{\text{стебель}} + (k \times 0.01\text{ мм})$$
  • $L_{\text{стебель}}$: Суурь цилиндр дээрх заалт (Доод зураас 0.5 мм-ийг заана)
  • $k$: Эргэлдэгч бөмбөрцөг (Барабан) дээрх хэвтээ тэнхлэгтэй давхцсан хуваарийн дугаар

Зургаас заалт унших:
1. Стебель дээрх заалт: $7.0\text{ мм}$ харагдаж байна ($0.5\text{ мм}$-ийн доод зураас цухуйгаагүй).
2. Барабан дээрх хэвтээ зураастай давхцсан тоо: $38$
$$\text{Нийт хэмжээ } L = 7.0\text{ мм} + (38 \times 0.01\text{ мм}) = \mathbf{7.38\text{ мм}}$$

👨‍🏫 4. Багшийн зөвлөгөө ба Алдаа

Багажуудын харьцуулалт

Үзүүлэлт Штангенциркуль Микрометр
Нарийвчлал 0.1 мм эсвэл 0.05 мм 0.01 мм (10 мкм)
Хэмжих зүйлс Гадаад, дотоод урт, савны гүн Нимгэн утасны диаметр, хуудасны зузаан
Гол онцлог хэсэг Нониусын хөдөлгөөнт хуваарь Түжигч хүрд (Ratchet stop)

💡 Сурагчдын гаргадаг түгээмэл 3 алдаа:

  1. Микрометрийг хэт чангалах: Эргүүлгийг хүчээр чангалбал багажийн эрээс гэмтэнэ. Заавал Ratchet stop хэсгээс барьж 2-3 удаа "чык-чык" хийх чимээ гартал эргүүлнэ.
  2. Микрометрийн 0.5 мм-ийн доод зураасыг анзаарахгүй орхих: Стебель дээр 0.5 мм-ийн доод зураас цухуйсан эсэхийг сайтар нягтлах хэрэгтэй.
  3. Нониусын 0 зураасыг биш, ирмэгийг харах: Штангенциркуль дээр заалт уншихдаа нониусын эхлэх ирмэгийг биш, 0 гэсэн зураасыг гол заагч болгоно.
