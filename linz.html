Физикийн хичээл: Цуглуулагч линз

9-р анги | Цуглуулагч линзэнд дүрс байгуулах ба линзийн өсгөлт

Бэлтгэсэн: Цаст-Алтай сургуулийн физикийн багш М.Амгалан

Цуглуулагч линз гэж юу вэ?

Дунд хэсгээрээ зузаан, захаараа нимгэн линзийг цуглуулагч линз гэнэ. Цуглуулагч линз дээр гол оптик тэнхлэгтэй параллелиар туссан гэрлийн цацрагууд линзээр хугарсны дараа линзийн ар талын нэг цэгт огтлолцон цуглардаг. Уг цэгийг линзийн бодит фокус (F) гэнэ.

Линзийн гэрэл цуглуулах зарчим:

Параллелиар туссан цацрагууд линзээр нэвтрэхдээ дотогш хугарч, ар талын бодит фокус ($F_2$) цэг дээр нэгдэн огтлолцдог. Иймээс цуглуулагч линзийг эерэг фокусын зайтай ($F > 0$) гэж үздэг.

Линзийн гол элементүүд:

  • Оптик төв (O): Линзийн геометрийн төв цэг. Энэ цэгийг дайрсан цацраг хугарахгүй шууд нэвтэрнэ.
  • Бодит Фокус цэг (F): Хугарсан цацрагууд цуглан огтлолцох цэг ($F > 0$).
  • Давхар фокус (2F): Фокусын зайнаас яг 2 дахин хол зайд орших цэг.
  • Гол оптик тэнхлэг: Линзийн оптик төв ба фокусуудыг дайрсан шулуун.

Дүрс байгуулахад ашиглах гол 3 цацраг:

Цуглуулагч линзэнд дүрс байгуулахад дараах 3 цацрагийн аль нэг хоёрыг ашиглана:

  • Параллель цацраг: Тэнхлэгтэй параллель туссан цацраг линзээр хугараад ар талын фокус ($F_2$)-ийг дайрна.
  • Оптик төвийг дайрах цацраг: Оптик төв ($O$) цэгийг дайрсан цацраг чиглэлээ өөрчлөхгүй шууд нэвтэрнэ.
  • Фокусыг дайрах цацраг: Урд талын фокус ($F_1$)-ийг дайран туссан цацраг хугарсны дараа тэнхлэгтэй параллель гарна.

Үүссэн дүрсний төлөв байдал ба хэрэглээ:

Цуглуулагч линзийн бодлогууд

Дараах 10 бодлогыг бие даан бодоод "Бодолт харах" товчлуур дээр дарж шалгаарай.

Бодлого 1

Цуглуулагч линзийн фокусын зай $F = 10\text{ см}$. Биеийг линзээс $a = 30\text{ см}$ зайд байрлуулсан бол дүрс линзээс ямар зайд ($b$) үүсэх вэ?

Бодолт:

Өгөгдсөн нь: $F = 10\text{ см}$, $a = 30\text{ см}$. ($a > 2F$ тул бодит дүрс үүснэ)

Нимгэн линзийн томьёо: $\frac{1}{F} = \frac{1}{a} + \frac{1}{b}$

Эндээс $\frac{1}{b} = \frac{1}{F} - \frac{1}{a} = \frac{1}{10} - \frac{1}{30} = \frac{3 - 1}{30} = \frac{2}{30} = \frac{1}{15}$

Хариу: $b = 15\text{ см}$ (Линзийн ар талд $15\text{ см}$ зайд бодит, урвуу, жижигрүүлсэн дүрс үүснэ).

Бодлого 2

Биетийг цуглуулагч линзээс $a = 20\text{ см}$ зайд тавихад линзийн ард $b = 20\text{ см}$ зайд бодит дүрс үүсев. Линзийн фокусын зай $F$-ийг олно уу.

Бодолт:

Өгөгдсөн нь: $a = 20\text{ см}$, $b = 20\text{ см}$.

Томьёо: $\frac{1}{F} = \frac{1}{a} + \frac{1}{b} = \frac{1}{20} + \frac{1}{20} = \frac{2}{20} = \frac{1}{10}$

Хариу: $F = 10\text{ см}$ ($a = 2F = 20\text{ см}$ учир биет давхар фокус дээр байсан ба адил хэмжээтэй дүрс үүссэн).

Бодлого 3

Кино проекторын линзийн фокус $F = 12\text{ см}$. Кино хальсыг линзээс $a = 18\text{ см}$ зайд байрлуулсан бол дэлгэц дээрх дүрс ($b$) ямар зайд үүсэх вэ? Шугаман өсгөлт $k$-г ол.

Бодолт:

1) $\frac{1}{b} = \frac{1}{F} - \frac{1}{a} = \frac{1}{12} - \frac{1}{18} = \frac{3 - 2}{36} = \frac{1}{36} \implies b = 36\text{ см}$.

2) Өсгөлт $k = \frac{b}{a} = \frac{36}{18} = 2$.

Хариу: $b = 36\text{ см}$, $k = 2$ дахин томруулна.

Бодлого 4

Марк цуглуулагч $F = 15\text{ см}$ фокусын зайтай луп (томруудаг шил)-ээр маркийг $a = 10\text{ см}$ зайнаас харав. Маркны дүрс ямар зайд үүсэх вэ?

Бодолт:

Өгөгдсөн нь: $F = 15\text{ см}$, $a = 10\text{ см}$. Энд $a < F$ тул хуурмаг дүрс үүснэ!

Томьёо: $\frac{1}{F} = \frac{1}{a} - \frac{1}{b} \implies \frac{1}{b} = \frac{1}{a} - \frac{1}{F} = \frac{1}{10} - \frac{1}{15} = \frac{3 - 2}{30} = \frac{1}{30}$

Хариу: $b = -30\text{ см}$ (Линзийн урд талд $30\text{ см}$ зайд хуурмаг, эгц, 3 дахин томруулсан дүрс харагдана).

Бодлого 5

Оптикийн хүч нь $D = +5\text{ дптр}$ байх цуглуулагч линзээс $a = 30\text{ см}$ зайд биетийг байрлуулав. Дүрс хүртэлх зай $b$-г олно уу.

Бодолт:

1) Фокусын зай $F = \frac{1}{D} = \frac{1}{5} = 0.2\text{ м} = 20\text{ см}$.

2) $\frac{1}{b} = \frac{1}{F} - \frac{1}{a} = \frac{1}{20} - \frac{1}{30} = \frac{3 - 2}{60} = \frac{1}{60} \implies b = 60\text{ см}$.

Хариу: $b = 60\text{ см}$.

Бодлого 6

$H = 6\text{ см}$ өндөртэй зүйл $F = 10\text{ см}$ фокустай линзээс $a = 15\text{ см}$ зайд байрлана. Дүрсийн өндөр $h$-ийг олно уу.

Бодолт:

1) $\frac{1}{b} = \frac{1}{10} - \frac{1}{15} = \frac{1}{30} \implies b = 30\text{ см}$.

2) Өсгөлт $k = \frac{b}{a} = \frac{30}{15} = 2$.

3) Дүрсийн өндөр $h = k \cdot H = 2 \times 6\text{ см} = 12\text{ см}$.

Хариу: $h = 12\text{ см}$.

Бодлого 7

Фотоаппаратаар $a = 40\text{ см}$ зайд байгаа зүйлийн зургийг авахад линзээс $b = 10\text{ см}$ зайд хальсан дээр дүрс буув. Линзийн фокусын зай $F$-ийг ол.

Бодолт:

$\frac{1}{F} = \frac{1}{a} + \frac{1}{b} = \frac{1}{40} + \frac{1}{10} = \frac{1 + 4}{40} = \frac{5}{40} = \frac{1}{8}$

Хариу: $F = 8\text{ см}$.

Бодлого 8

$F = 20\text{ см}$ фокусын зайтай цуглуулагч линзийн ард $b = 60\text{ см}$ зайд бодит дүрс үүссэн бол биет линзээс ямар зайд ($a$) байсан бэ?

Бодолт:

$\frac{1}{a} = \frac{1}{F} - \frac{1}{b} = \frac{1}{20} - \frac{1}{60} = \frac{3 - 1}{60} = \frac{2}{60} = \frac{1}{30}$

Хариу: $a = 30\text{ см}$.

Бодлого 9

Биетийг цуглуулагч линзээс $a = 10\text{ см}$ зайд байрлуулахад 2 дахин томруулсан хуурмаг дүрс ($k = 2$) үүсэв. Линзийн фокус $F$-ийг олно уу.

Бодолт:

1) $k = \frac{b}{a} \implies b = k \cdot a = 2 \times 10\text{ см} = 20\text{ см}$.

2) Хуурмаг дүрс тул: $\frac{1}{F} = \frac{1}{a} - \frac{1}{b} = \frac{1}{10} - \frac{1}{20} = \frac{1}{20} \implies F = 20\text{ см}$.

Хариу: $F = 20\text{ см}$.

Бодлого 10

$H = 4\text{ см}$ өндөртэй биеийг линзийн өмнө $a = 50\text{ см}$ зайд тавихад $h = 1\text{ см}$ өндөртэй бодит дүрс үүссэн бол линзийн оптикийн хүч $D$-г олно уу.

Бодолт:

1) Өсгөлт $k = \frac{h}{H} = \frac{1}{4} = 0.25$.

2) $b = k \cdot a = 0.25 \times 50\text{ см} = 12.5\text{ см}$.

3) $\frac{1}{F} = \frac{1}{50} + \frac{1}{12.5} = \frac{1 + 4}{50} = \frac{5}{50} = \frac{1}{10} \implies F = 10\text{ см} = 0.1\text{ м}$.

4) Оптикийн хүч $D = +\frac{1}{F} = \frac{1}{0.1\text{ м}} = +10\text{ дптр}$.

Хариу: $D = +10\text{ дптр}$.
